1616 Transfer Dashboard — public LWServers import

Open index.html in a browser. All Players contains 11,057 unique player IDs from all 32 public player snapshots for servers 1605–1636, downloaded September 18, 2026 Pacific time. This is all available data in those snapshots, not a guarantee that every game account is represented or current. Raw source snapshots and a retrieval manifest are included in source-data.

Application matching: open the sidebar entry, choose Load test ID match, then Check for matches. The example is a simulated application, not a real submission. Review identity and choose which conflicting fields to update. Linking reuses the player record and retains notes, assignments, reminders and the original source snapshot. Duplicate application references are blocked for the session. Without an exact ID, name/server/alliance candidates require human review. Names do not establish identity.

All imported players start as Contacts with status Unknown, no known seats, no ownership claims or invented notes. Zero total hero power is displayed as unknown; original source values are retained. Kills measurement dates are unknown. THP source dates and legacy flags appear in profiles. Retrieval time is not a gameplay activity date.

Player profiles show general information first, followed by collapsible sections. Follow-ups can be scheduled multiple times, completed and rescheduled. The dashboard has a separate Completed view; completed reminders remain in history. Reminders appear in the app only. No email, push or background notifications are sent.

IMPORTANT: This is a local interactive prototype. Player edits, matching decisions, assignments and reminders last only for the current session. It is not connected to Google Sheets, Firebase, live submissions or automatic LWServers refresh. Permission controls are not production security. Do not use this file as a shared live database. The full imported data is bundled locally; publishing the file would publish that data.

Interface language: top-right selector offers English, Korean, Vietnamese, German, French, Portuguese and Spanish. Navigation, common controls and profile sections are translated; untranslated descriptive text falls back to English. Player names, source data, notes and recorded history remain as entered. Language is saved in browser-local preview settings; it is not a Google Sheets permission or shared setting.
